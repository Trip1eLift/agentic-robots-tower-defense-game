Pixel Art Style Direction

Minecraft-inspired blocky world, but ARIA units are prettier and more detailed. Pick the approach that fits best.

A

16-bit SNES Style (Recommended)

ARIA units: 32x32 with 8-12 color palettes per character. Smooth, expressive feminine silhouettes with class-distinct profiles (bulky vanguard, slim striker, flowing medic). Hair and eye detail visible.

World: 16x16 tiles with chunky Minecraft-like terrain. Blocky rubble, simple grass/dirt, crude walls. High contrast between pretty characters and rough world.

Zombies: 32x32 with fewer colors (4-6), grotesque blocky shapes. Clearly enemies at a glance.

Think: Final Fantasy VI characters on a Minecraft map

B

Uniform 32x32 Everything

All sprites 32x32 with consistent detail level. ARIA units get more color depth (10-14 colors) vs world tiles (4-6 colors). World uses 32x32 tiles too -- less blocky than Minecraft but still chunky.

ARIA units: Detailed with visible armor, weapons, hair color. Each class has a unique silhouette and color scheme.

Zombies: Same size but muddier colors, asymmetric shapes.

Think: Stardew Valley character detail on a post-apocalyptic map

C

48x48 ARIA, 16x16 World

ARIA units: 48x48 -- large, detailed, almost chibi-anime style. Visible facial expressions, flowing hair, detailed weapons and armor plating. The stars of the show.

World: 16x16 tiles -- very blocky Minecraft terrain. Crude but functional.

Zombies: 32x32 -- mid-size, threatening but clearly less detailed than ARIA.

Think: Detailed character portraits walking on a low-res blocky world

Current State

All sprites are simple colored rectangles: robots 32x32, zombie 32x32, base 64x64, walls/barricades 16x16. The game is playable but visually bare.
